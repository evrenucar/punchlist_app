Keyboard shortcuts

Punchlist is built to run without the mouse. These five carry a whole session; everything below them is there for when you need it. Ctrl is Cmd on a Mac.

Enter
New task
Tab
Make it a subtask
Ctrl+Enter
Tick it off
Alt+↑↓
Move it anywhere
Ctrl+Alt+F
Focus on one thing

Writing

Enter
Adds a task below the one you are on.With the caret at the start of a line that already has text, the new task goes above instead.
Shift+Enter
A line break inside the same task.
Tab/Shift+Tab
Indent or outdent.Works on a whole multi-selection at once.
Alt+A
New group.
Backspace/Delete
Delete what is selected.Recoverable from Trash, and Ctrl+Z brings it straight back.
Ctrl+Z
Undo the last board change.

Getting around

↑↓
Previous or next row.Inside a task with several lines, they move the caret first and only then change row.
←
Climb one level: subtask to parent, parent to group header, group header to the sidebar.
↑
From the very top task, reaches the search box.
Shift+↑↓
Extend the selection to more rows.
Esc
Clears the search box, closes focus mode, cancels a delete confirmation.

Moving and folding

Alt+↑↓
Move the task itself.It travels through subtrees and across groups, not just between siblings.
Alt+←→
Change its depth without moving it up or down.
Ctrl+↓/↑
Expand or collapse what is selected.Works while you are typing in the task, and inside focus mode on the outline.
Ctrl+Shift+↓/↑
Expand or collapse everything on the board.

Doing the work

Ctrl+Enter
Tick the selected task off, or untick it.
Ctrl+D
Put a copy of the selected task in Today.A linked copy unless Settings says otherwise, so ticking either one ticks both.
Ctrl+Alt+F
Focus mode on the selection, one task and its children alone on screen.Works on a group too. Esc leaves.

Formatting a task

Ctrl+B
Bold.
Ctrl+I
Italic.
Ctrl+Shift+S
Strikethrough.

These write plain Markdown into the task, so a copy or an export carries the formatting with it. Pressing the same pair again takes it back off. The task you are typing in shows its markers and every other row stays formatted; Settings → Formatting changes that, and turns these keys off.

Copy and paste

Ctrl+C
Copy the selection as clean Markdown, ready for anywhere else.
Ctrl+X
Cut. Paste it somewhere else to move it.
Ctrl+V
Paste. Inside the board this makes a linked copy by default; Settings changes that.Markdown pasted from outside becomes real tasks, nesting and all.
Ctrl+Shift+V
Paste an independent copy, whatever the setting says.

The sidebar and settings

Alt+S
Show or hide the sidebar.
←
From a group header, hands focus to the sidebar.
↑↓
Walk the sidebar, straight through the settings inside an open section.
→
Open the section you are on. On anything else, hands focus back to the board.
←
Close the section you are on, then climb to the one that holds it.
Ctrl+↓/↑
Open or close a section outright, the same pair the board uses.
Space
Flip the checkbox you are on.
Alt+↓
Drop open the menu you are on, then arrows pick and Enter takes it.

A text field keeps ← and → for its own caret, so typing a repository name works normally. Up and down still walk out of it.
